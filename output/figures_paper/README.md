# Paper Figures Output

This directory is reserved for paper-ready figures generated from existing project results.

Suggested subdirectories:

- `maps/`: modern and paleoclimate suitability maps
- `trends/`: area and suitability trend figures
- `model_diagnostics/`: variable selection and model evaluation figures
- `fossil_comparison/`: fossil-model comparison figures
- `tables/`: figure-ready summary tables

Do not overwrite historical outputs in `output/10_visualization/` or `output/10_visualization_teyf/`; copy or regenerate revised figures here.
