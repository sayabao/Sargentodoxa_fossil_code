# Sargentodoxa: code and data

**Deep-time biogeographic history of the East Asian endemic Sargentodoxa (Lardizabalaceae): fossil revision, ancestral-range reconstruction and niche modelling**

This repository contains the analysis scripts, input data and processed results supporting the manuscript.

| Directory | Contents |
| --- | --- |
| [niche_modelling](niche_modelling/README.md) | Occurrence processing, variable selection, model calibration and evaluation, modern and palaeoclimate projections, and fossil–projection consistency tests |
| [ancestral_range_reconstruction](ancestral_range_reconstruction/README.md) | Molecular phylogeny, divergence-time estimation and fossil-informed ancestral-range reconstruction |
